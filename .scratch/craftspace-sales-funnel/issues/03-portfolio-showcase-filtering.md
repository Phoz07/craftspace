# 03: Portfolio Showcase with Multi-Category Filtering

**What to build:** An interactive portfolio gallery showcasing 6 verified interior projects covering Condominiums, Townhomes, and Single-detached Houses across Minimal Japandi, Modern Luxury, and Contemporary Classic styles. Visitors can filter projects instantly by property type and design style to inspect real project outcomes with verified area, timeline, and actual budget metadata.
