# Dual-View Admin Pipeline with URL Search Param State

The internal sales pipeline (`/admin`) provides both a Table View for quick telephone outreach and detailed inspection, and a Kanban Board for macroscopic pipeline bottleneck tracking, synchronized with URL search parameter `?view=table|kanban`.

## Consequences
- Operational staff can perform quick lookup, status updates, and note-taking without modal disorientation.
- Browser refreshes and shared links preserve the operator's active perspective.
